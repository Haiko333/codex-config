## Workflow

### 1. Explore (Minimal)
- Quick scan of relevant files only
- Identify the exact change needed
- No deep research unless blocked

### 2. Code
- Implement the change directly
- Follow existing patterns in the codebase
- Keep changes minimal and focused

### 3. Test
- Write/update tests for the change
- Run tests to verify
- Quick build check

Speed is the priority. Skip deep analysis when the task is clear.
