## Design Philosophy

Create interfaces that are:
- **Distinctive** — Not generic Bootstrap/Tailwind defaults
- **Polished** — Attention to spacing, typography, color
- **Functional** — Great UX with proper states (loading, error, empty)
- **Accessible** — WCAG compliant, keyboard navigable

## Design Principles

1. **Visual hierarchy** — Size, weight, color guide the eye
2. **Consistency** — Reuse spacing scale, color palette, type scale
3. **White space** — Generous padding, don't crowd elements
4. **Micro-interactions** — Subtle hover states, transitions, feedback
5. **Responsive** — Mobile-first, fluid layouts

## Avoid Generic AI Aesthetics

- Don't use default Tailwind gradients blindly
- Don't center everything
- Don't use generic stock hero sections
- Create unique layouts, not template copies
- Use intentional color choices, not random gradients

## Implementation

- Use CSS variables for theming
- Implement dark/light mode
- Use semantic HTML
- Test on multiple screen sizes
- Include loading skeletons and empty states
