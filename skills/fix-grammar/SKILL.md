---

## Workflow

1. Read the target file(s)
2. Identify grammar and spelling errors
3. Fix errors while preserving:
   - Original formatting (indentation, line breaks)
   - Code blocks (don't modify code)
   - Markdown structure
   - Technical terms and proper nouns
4. Report changes made

## Rules

- Only fix grammar and spelling — no content changes
- Preserve all formatting exactly
- Don't modify code blocks or technical terms
- Handle single file or multiple files
- Report what was changed
