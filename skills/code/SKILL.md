## Workflow

### Phase 1: Explore Context
- Explore the codebase for relevant files and patterns
- Research library documentation for APIs needed
- Search web for solutions if needed
- Run all exploration in parallel

### Phase 2: Plan
- Based on gathered context, create an implementation plan
- Identify files to create/modify
- Plan test strategy
- Present plan for user approval

### Phase 3: Execute
- Follow the approved plan
- Write tests first (TDD approach)
- Implement changes
- Run code review after modifications

### Phase 4: Validate
- Run tests
- Verify build passes
- Check coverage
- Final review
